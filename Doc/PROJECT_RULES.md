# เอกสารควบคุมและบันทึกการทำงานโปรเจค (Project Documentation & Changelog)

**ชื่อโปรเจค:** ระบบจัดการอบรมพนักงาน (Training Management System)
**บริษัท:** บริษัท วีอาร์ คอนเทนเนอร์ จำกัด

---

## 1. กฎกติกาของการทำโปรเจค (Project Rules)

- **ความกระชับและตรงจุด:** เน้นการพัฒนาฟีเจอร์ที่ตอบโจทย์การใช้งานจริงและทำงานจบในตัวได้
- **คำศัพท์เฉพาะของบริษัท (Domain Knowledge):** 
  - *แผนก:* จัดซื้อ, วางแผนการผลิต, แปรรูปไม้สด, เตรียมวัตถุดิบ (เตรียมไม้), คลังวัตถุดิบ (คลังสินค้า), QC ตรวจรับ, สำนักงาน
- **ขอบเขตการทำงานเฟสปัจจุบัน:**
  - ครอบคลุมระบบ 5 ชั้น: ข้อมูล(Data) ➔ ธุรกรรม(Transaction) ➔ ตรรกะ(Logic) ➔ สรุปยอด(Dashboard) ➔ แจ้งเตือน(Alerts)
- **ฟีเจอร์ที่เลื่อนไปทำเฟสถัดไป (Out of scope for Phase 1):**
  - อัปโหลดไฟล์แนบ/สแกนใบรับรอง
  - ระบบ Login แบ่งสิทธิ์พนักงาน/ผู้ดูแล
  - การส่งข้อความแจ้งเตือนผ่านช่องทางอื่น (Email / LINE)

---

## 2. ระเบียบและข้อมูลพื้นฐาน (Tech Stack & Foundation)

### 💻 Tech Stack ที่ใช้งาน
- **Frontend Framework:** Next.js (App Router)
- **Styling:** Tailwind CSS (เน้นความสวยงามระดับ Premium Design, ใช้โทนสี Emerald / Slate)
- **Icons:** Lucide React
- **Charts:** Recharts (สำหรับกราฟสรุปยอด)
- **Database:** Supabase (PostgreSQL) — *ปัจจุบันใช้ระบบ Mock Data แบบ Client State เพื่อทำตัวต้นแบบ (Prototype) รอเชื่อมต่อ Database จริง*

### 🧱 โครงสร้างข้อมูลหลัก 3 ตาราง
1. **ข้อมูลหลักสูตร (Courses):** รหัส, ชื่อหลักสูตร, หมวดหมู่, หลักสูตรบังคับ(ใช่/ไม่), ชั่วโมงอบรม, อายุใบรับรอง (ปี)
2. **ข้อมูลพนักงาน (Employees):** รหัสพนักงาน, ชื่อ-สกุล, แผนก, ตำแหน่ง
3. **บันทึกการอบรม (Training Records):** พนักงาน, หลักสูตร, วันที่อบรม, วิทยากร, คะแนนสอบ (0-100)

### ⚙️ ตรรกะระบบ (Business Logic)
- **การประเมินผล:** คะแนนตั้งแต่ `70` ขึ้นไป = ถือว่า **"ผ่าน"**
- **วันหมดอายุ:** `วันที่อบรม + จำนวนปีของอายุหลักสูตร` (ถ้าหลักสูตรตั้งอายุเป็น `0` = ไม่มีวันหมดอายุ)
- **ชั่วโมงสะสม:** ระบบจะนับรวมเฉพาะชั่วโมงของหลักสูตรที่ผลการสอบเป็น "ผ่าน" เท่านั้น
